# Manuscript Integration

## Purpose

Use this skill only for explicit workflow-design or readiness-boundary questions
about manuscript integration. It is not the owner of any substantive manuscript
production stage.

Current ownership boundaries:

- Claim graph refresh belongs to the standalone `claim-graph-integration` skill.
- Section change assessment belongs to the standalone
  `manuscript-section-change-assessment` skill.
- Figure work, legends, Results, Methods, rendering, and final assembly remain
  owned by their own workflow skills.

This skill should not create new manifests, crosswalks, evidence mappings,
section annotations, graph edits, prose, legends, or rendered manuscript outputs.

## Allowed Work

When explicitly requested, this skill may:

- inspect existing workflow skills and current project plans;
- summarize current ownership boundaries;
- identify dependency risks between workflow stages;
- propose a revised manuscript-integration boundary;
- write a short design note or migration checklist requested by the user.

Keep this work at the workflow-design level. Do not run stage-owner workflows
from here.

## Completion Standard

Finish with a concise boundary/design summary and any concrete files inspected
or changed. If a requested task requires substantive stage work, stop and route
the user to the owning standalone skill rather than executing it here.
