# Source-table provenance

These tables make the polishing package independent of the temporary rough-plot folder. They are exact copies of the tables used for the user-reviewed exploratory plots.

- `ploidy_effect_metric_values.csv` was generated by the package-local `scripts/make_condition_source_tables.R` from the three fitted Stan datasets and `config/parameter_estimation/morphology_metrics_a30_20260729/pair_map.tsv`.
- `condition_delta_loglik_summary.csv` was generated by the same script from the best-MAP `ll_well` values in `data/modelling/gpath_v1/morphology_metrics_a30_20260729/` and the current ploidy release `data/modelling/gpath_v1/red_a30_counts_20260722/`. The five model identifiers and their order are now derived from that release's all-lines Pareto assessment.
- `realized_parameter_effects_by_metric.csv` was generated by the package-local `scripts/make_parameter_effect_source_tables.R` by reconstructing physical parameters from the best MAP fit for each of the five current all-lines Pareto models and three covariate definitions.
- `per_unit_parameter_effect_coefficients.csv` was generated by the same script and records the global reconstructed log2 parameter change for a +1 shift in each fitted covariate.

The morphology fits use the area metrics derived exclusively from alive objects observed at 24--48 hours inclusive in the corrected image-classification run:

`data/image_processing_runs/full_segmentation_classification_nuclear/run_20260721_163410/`
