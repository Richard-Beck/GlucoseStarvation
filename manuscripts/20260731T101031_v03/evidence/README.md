# Evidence

- `claim_graph/` records the accepted clean claim graph and reconciliation.
- `methods/` records the current locked provenance table, figure endpoints,
  drafting audit, and handoff.
- `results/` retains the Results validation and recycling audit.
- `legends/` retains the approved legend validation.
- `abstract_introduction_discussion/` preserves the complete ordered serving
  bundle and its source hashes.

Together with `rebuild/figures/figure_rebuild_manifest.tsv`, these records map
every displayed figure to its generation package and declared datasets.
